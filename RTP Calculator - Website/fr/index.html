Mentions

Politique de confidentialité

Le Calculateur de TRJ ne demande ni compte ni inscription. Vos analyses sont enregistrées uniquement sur votre appareil (application Android) ou dans votre navigateur (calculateur en ligne), jamais sur un serveur. Le site mesure son audience avec Google Analytics ; l'application Android affiche des publicités Google AdMob.

Lire la politique de confidentialité complète →

Suppression des données

Effacez les données de l'application dans les paramètres Android ou désinstallez-la ; pour le calculateur en ligne, effacez les données de site de votre navigateur pour rtpcalculator.com. Pour toute autre demande, écrivez à contact@rtpcalculator.com : réponse sous 30 jours.
