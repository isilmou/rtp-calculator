Application disponible sur navigateur et sur mobile

Le Calculateur de TRJ existe en deux versions gratuites et sans inscription avec les mêmes fonctionnalités :

Version navigateur

Saisissez les cotes d'un pari et obtenez son TRJ instantanément. Prend en compte les formats de cote décimales (EU), fractionnaires (UK) et américaines (US). Le nombre d'issues que vous pouvez saisir est illimité. L'historique est conservé dans votre navigateur.

Application Android

Les mêmes fonctionnalités à la différence que les sauvegardes de vos analyses se font en local sur votre smartphone. Comme pour la version navigateur, vous avez la possibilité de partager en image vos analyses.

Politique de confidentialité

Le Calculateur de TRJ ne demande ni compte ni inscription. Vos analyses sont enregistrées uniquement sur votre appareil (application Android) ou dans votre navigateur (calculateur en ligne), jamais sur un serveur. Le site mesure son audience avec Google Analytics ; l'application Android affiche des publicités Google AdMob.

Lire la politique de confidentialité complète →

Suppression des données

Effacez les données de l'application dans les paramètres Android ou désinstallez-la ; pour le calculateur en ligne, effacez les données de site de votre navigateur pour rtpcalculator.com. Pour toute autre demande, écrivez à contact@rtpcalculator.com : réponse sous 30 jours.
